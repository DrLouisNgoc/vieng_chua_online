# Decision 0001: Personal use only, never shared or published

Date: 2026-11-02

## Decision
This app is for the owner's private, personal use only. It will never be
shared, published, distributed, or monetized in any form.

## Why
The project reuses copyrighted assets (images, 3D models, audio, text) from
sansatemple.com. Reusing those assets is legally gray even for personal use;
restricting the result to strictly private, non-distributed use is the
mitigation the owner explicitly chose.

## Consequences
- No public deploy, no app store release, no sharing the packaged app or its
  assets with anyone else.
- No bypassing of any DRM/anti-copy protection on the source site; only use
  assets reachable via normal public browsing.
- If the owner later wants to share/publish, assets must first be replaced
  with originals (see decision 0003) — this ruling does not cover that case.

Ruling: keep original sansatemple.com assets, restricted to strictly private
personal use — chosen by owner over the safer "recreate with original assets"
alternative — cost if wrong: copyright exposure if the app is ever shared,
published, or leaked beyond the owner's own device.
